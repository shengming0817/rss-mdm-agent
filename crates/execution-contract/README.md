# execution-contract

本地执行值类型、预算校验与不可变计划摘要，不定义服务端 Agent wire。外部字节必须有界解码并冻结；存储读取重新冻结并比对原摘要。DTO、结构合法与摘要匹配均不证明身份、批准或执行证据真实。

完整计划参与规范摘要，执行方只使用冻结后的值。秘密只以版本引用传递，不能放入 argv 或普通 literal。参数保持独立，不拼接 shell；环境不默认继承，路径语法校验不替代真实路径与符号链接核验。runner 负责物化精确产物、隔离、IO 编码与累计预算。

主体、发起来源、目标用户和运行身份分别记录；同名账号不能相互授权。审计只保存关联引用和闭合原因，不回显参数或输出。格式、规范化算法和预算由 [src](src/) 的 rustdoc 持有，schema 由 [examples](examples/) 生成；不手写第二份摘要定义。
