# software-plan

软件期望与核实决策纯核心，只选择下一步，不调用安装器、不求解依赖、不授权执行。宿主认证事实来源、时效与完整上下文；Ready 仍需在执行前取得锁并重新准入。

包坐标精确匹配，不做 latest 回退或通用 SemVer 推断；不同版本顺序来自生态 owner 的可信比较。进程退出不能替代独立检测，未知结果、取消后效果不明和重启后均须重新检测。

保护用户已有软件：未知 ownership 阻止变更，卸载、降级和重启分别受政策限制。未声明依赖影响不能盲目变更，已满足目标不自动接管软件。具体决策和诊断见 [src](src/)，来源见[执行核心来源](../../docs/reference/execution-cores.md#c10c11-脚本与软件计划)。
