# execution-approval

判断精确批准是否适用并产生消费意图，不签发批准、不写数据库、不调用执行器。消费完整授权裁决；只有需要批准的裁决才核验全部要求，普通拒绝不能被批准覆盖。

可信 verifier 核验批准者权限、受保护来源、完整计划摘要、撤销及可靠时间。普通问题回答和模型 DTO 不构成批准。批准范围直接复用冻结摘要，避免第二套字段投影漂移。

每个新尝试重新准入，对每份不同记录消费一次；同一记录覆盖多个要求仍只扣一次。存储在同一受保护事务内复核授权新鲜度、版本、计数与唯一性，并提交批准消费、intent、状态和审计。只有首次提交释放派发值；重放、冲突和结果不明均不能再造派发。事务失败不消费，已接纳后失败不自动退款。

API 见 [src](src/)，机制来源见[执行核心来源](../../docs/reference/execution-cores.md)。
