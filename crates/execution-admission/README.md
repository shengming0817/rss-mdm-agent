# execution-admission

确定性执行授权核心，只产生裁决，不签发批准或执行许可。宿主 verifier 必须独立认证主体、来源、委托、受保护政策与可靠时间；不能将冻结计划回显为授权事实。纯库不防御恶意同进程宿主。

每次尝试独立核验。精确范围来自完整冻结计划，委托与主体基础权限取交集，不能拼接不同规则的部分预算；拒绝优先，全部必需批准要求同时成立，没有匹配或可信输入失败均拒绝。普通拒绝不能由一次用户点击升级为可批准。

裁决绑定当前尝试和可信新鲜期，原子接纳时仍需复核政策、撤销与历史唯一性；克隆结果不产生新的授权。穷尽字段处理使新增计划语义必须先明确授权归属。公开 API 与匹配规则见 [src](src/)。
