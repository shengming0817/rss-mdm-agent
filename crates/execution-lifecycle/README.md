# execution-lifecycle

无 IO 的执行生命周期核心，计算状态转换与后续建议；数据库原子性归存储，执行准入归应用服务。候选转换只有可信提交后才成为事实，首次成功接纳才能释放一次性派发值。

派发值不持久化、不复制；提交后崩溃或响应丢失只能核实，不能从快照再造首次执行。普通命令与可信观察分开，后者须验证来源、原计划、尝试和 runner 绑定。

取消是停止意图，父进程退出不必然证明子工作停止，退出零不等于效果达成。只有权威未派发或已停止且无效果的事实才允许考虑新尝试；未知和可能已有副作用要求人工核对。每次尝试重新授权，等待、重试和丢弃输出不重置总预算。

恢复只接受当前格式，保留原始派发事实；快照不是许可。测试证据不得变成真实执行证据。状态、预算和恢复 API 见 [src](src/)，来源见[执行核心来源](../../docs/reference/execution-cores.md)。
