# script-plan

把已展开的字面参数、精确脚本/解释器引用和显式 IO 编译为唯一的 `LaunchSpec`。后台脚本、软件脚本与已有受控包装脚本消费相同文件调用规则；完整任务、执行身份、预算及冻结由各自外层持有。

参数逐项保留原值和顺序，不绑定目录参数、不插值、不拼接 shell 源码、不再次 tokenize。编译不读取、验签、发布或执行材料，不产生另一份摘要。调用输入仅服务本地编译，不是 wire 或持久化格式。

runner 在实际执行边界独立核验 profile/revision、平台允许集合、真实材料与编码、环境、stdin 和身份；共同规则不授予平台支持或执行权限。受控工具可仅复用文件启动约定，工具及材料校验仍由其 owner 持有。osquery、native worker 和原生安装器保持独立语义。

接口与限制由 [src](src/) 持有。来源见[执行核心来源](../../docs/reference/execution-cores.md#c10c11-脚本与软件计划)。
