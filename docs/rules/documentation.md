# 文档维护

PRD唯一入口为[docs/product/rss-mdm-agent-prd.md](../product/rss-mdm-agent-prd.md)。稳定规则不复制功能需求和进度。

产品需求归product，设计决策归architecture，操作说明归guides，来源归reference，稳定协作规则归rules；新增材料更新[文档导航](../README.md)。
固定入口使用稳定名称；过程文档使用`yyyyMMddHHmm-编号-实际功能或问题.md`，时间统一UTC。
引用指向实际存在的文件或可定位来源；需求编号保持稳定，目标/来源/实现/验证分开标识。
Issue状态、父子和滚动实施顺序只在tracker，不建立本地backlog副本。临时验证、账号配置、密钥和个人技能入口不入库。

仅当读者操作、外部接入/部署步骤或理解产品边界所必需的信息变化时，更新已有对应入口。内部实现和测试变化不默认改文档，不要求顺带更新 PRD。
新文档必须有现有入口无法承载的长期读者需求；实现过程与逐次验证结果留在 PR 或已有持久制品。
类型、字段、常量、依赖版本和测试清单由代码、schema、manifest 与现有生成物持有；文档说明用途、取舍和操作，不维护手写副本。
