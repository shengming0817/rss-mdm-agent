# AI 客户端

基于 Web Streams 的统一会话投影，可由浏览器或桌面通道消费。先协商，再创建或恢复会话；接口见 [src](src/)，接入顺序见[开发指南](../../docs/guides/ai-access-development.md)。

恢复先收齐同一水位历史再原子发布，随后接续稳定事件；序列缺口、游标过期或非法内容要求显式重新同步。临时文本不能覆盖稳定终态，回执不制造乐观消息。传输 attached 与持久会话健康分别显示。

重试保留原命令、完整内容和期限。恢复显示与恢复模型上下文分别操作；关闭视图不取消模型。个人连接与历史预览由可信通道绑定当前用户，客户端不提交 caller 或秘密。历史带入须由用户确认，连接删除仍保留已有历史。

公开错误保持闭合类别；观察者或诊断回调失败不能改变投影。页面不再维护第二份 replay、bridge 或恢复状态机。
