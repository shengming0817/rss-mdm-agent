# A2UI schema provenance

Unmodified client action/error and server surface lifecycle schemas, basic catalog and common types and Apache-2.0 LICENSE from
[a2ui-project/a2ui](https://github.com/a2ui-project/a2ui/tree/04e6f07fde12ff2638b3b489bd9e3033066cb957).
Sources under `specification/v0_9_1`: `json/client_to_server.json`, `json/server_to_client.json`, `json/common_types.json`, and `catalogs/basic/catalog.json`.
The basic catalog is explicitly registered at the server schema’s `catalog.json` reference; files and `$id` values remain unchanged. Custom catalog/renderer validation remains the access adapter’s responsibility.
Revision: `04e6f07fde12ff2638b3b489bd9e3033066cb957`.
Copyright belongs to the upstream A2UI authors. This is a fixed official schema snapshot, not an interoperability result.
The product negotiates only v0.9.1 even though this unchanged schema also describes v0.9.

Fixed file SHA-256 values are owned by [manifest.json](manifest.json). Generation and `check:ai-contract` verify every listed file before compiling validators.
