# ACP 接入

将公共 Host 转为官方 ACP stream 与协商后的产品扩展。可信组合根绑定 caller，请求、模型和卡片不能提供身份。标准 prompt 等待终态；资源链接只显示为文本，不自动读取 URI 或文件。

每个连接持有自己的请求和订阅，关闭连接不关闭共享 Host 或取消已接纳工作。恢复展示与原生续接分开，续接后明确重新同步。标准权限只转交实时回调，首个有效回答生效；断开后不复活回调，也不签发 Rust 执行批准。

接纳预算不截断长期订阅或伪造终态。关闭有界等待自身资源，超时仍由组合根隔离残留 provider。公开错误与诊断不包含底层正文。入口与配置见 [src](src/)，接入操作见[开发指南](../../docs/guides/ai-access-development.md)。
